# adaptek

The website of **Adaptech**, an academy for learning computational thinking without computers ("berpikir komputasi tanpa komputer"), initiated by two South Sumatera natives, **Sofian Hadiwijaya** and **Irvan Putra**. The site (in Bahasa Indonesia) announced the first Computational Thinking Study Camp in South Sumatera and describes the academy's principles.

It is a single static page served with GitHub Pages at <https://vanipy.com/adaptek/>. The `www.adaptech.id` domain lapsed, so the custom-domain setting was dropped in November 2026. The page was written by hand in 2020, before AI assistance was in use.
